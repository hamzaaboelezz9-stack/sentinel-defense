# SENTINEL DEFENSE 1.0.0
Integrated educational engineering release. All eight workstreams are represented in one connected/offline application. See CHANGELOG.md for implementation changes and docs/ACCEPTANCE.md for the precise execution evidence.

Upgrade from the preview: back up the local database first. Preserve the entire extracted directory and original credentials. Normalized startup import preserves legacy records and analyst histories. Explicit migration instructions cover versioned and unversioned databases. Hosted browser data remains browser-local; the private site does not execute the Python backend.

No claim of military endorsement, production readiness, operational-network validation, universal vulnerability freedom, or unexecuted CI/Windows success is made.
